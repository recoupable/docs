<Note>
This is the canonical endpoint for subscription checkout on the Recoup API (`POST /api/subscriptions/sessions`). It replaces the former chat-only route `POST /api/stripe/session/create` — call the API base URL from [Quickstart](/quickstart#base-url), not the chat app host.
</Note>
