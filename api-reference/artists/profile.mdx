---
title: "Get Artist Profile"
openapi: "/api-reference/openapi/releases.json GET /api/artists/{id}/profile"
---

The response includes measured recordings even when no catalog has been saved.
Artist accounts linked to the same exact Spotify artist profile share the same
credited-recording lookup; an artist name alone is never used to join profiles.

Measured songs outside saved catalogs appear under **Recorded songs**. This group is for
display only: its `id` is the artist UUID, not a catalog you can edit. Its
`updated_at` is the latest recording measurement. Each group returns up to 1,000
songs in descending play-count order.
