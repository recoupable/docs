---
title: "Create an artist"
description: "End-to-end 8-step process for creating, identifying, and enriching a new artist account from a single name."
---

Triggers on "create artist", "onboard X", "add this artist", "set up a new artist", or any task that starts a brand-new artist record from a name. For editing or extending an *existing* artist, use [Work with an artist](/skills/artist-workspace) instead.

## Install

```bash
npx skills add recoupable/skills --skill create-artist
```
