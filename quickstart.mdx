## Base URL

```
https://api.recoupable.com/api
```

## Step 1: Get an API key

1. Go to [chat.recoupable.com/keys](https://chat.recoupable.com/keys)
2. Sign in to your account
3. Enter a name for your key (e.g. `"Development"`) and click **Create API Key**

<Warning>
Copy your key immediately — it is only shown once and cannot be retrieved after creation.
</Warning>

## Step 2: Make your first request

Search Spotify for an artist — this works immediately with no additional setup:

<CodeGroup>

```bash cURL
curl "https://api.recoupable.com/api/spotify/search?q=Drake&type=artist" \
  -H "x-api-key: YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.recoupable.com/api/spotify/search",
    params={"q": "Drake", "type": "artist"},
    headers={"x-api-key": "YOUR_API_KEY"},
)
print(response.json())
```

```javascript JavaScript
const response = await fetch(
  "https://api.recoupable.com/api/spotify/search?q=Drake&type=artist",
  { headers: { "x-api-key": "YOUR_API_KEY" } }
);
const data = await response.json();
console.log(data);
```

</CodeGroup>

## Authentication reference

All requests require your API key in the `x-api-key` header. For frontend apps using Privy, you can pass a Bearer token instead. See the [Authentication guide](/authentication) for full details.
