The Recoup CLI (`@recoupable/cli`) gives you the full platform from your terminal. Manage artists, generate content, check task status, and automate workflows.

The default flow is:

1. Authenticate with `recoup whoami`
2. Browse your roster with `recoup artists list`
3. Create content with `recoup content create`
4. Monitor with `recoup tasks status`

## Installation

```bash
npm install -g @recoupable/cli
```

## Authentication

Set your API key as an environment variable. Get one from the [API Keys page](https://chat.recoupable.com/keys).

```bash
export RECOUP_API_KEY=your-api-key
```

Verify your session:

```bash
recoup whoami
```

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `RECOUP_API_KEY` | Yes | — | Your Recoup API key |
| `RECOUP_API_URL` | No | `https://recoup-api.vercel.app` | API base URL override |

All commands support `--json` for machine-readable output and `--help` for usage info.

## Content creation workflow

This is the primary workflow for generating social-ready artist videos.

### Step 1: Check available templates

```bash
recoup content templates
```

### Step 2: Validate artist readiness

Before creating content, verify the artist has the required assets (songs, face guide, brand docs).

```bash
recoup content validate --artist <artistAccountId>
```

### Step 3: Estimate cost

Preview cost and duration without starting a run.

```bash
recoup content estimate --artist <artistAccountId>
recoup content estimate --artist <artistAccountId> --template artist-caption-bedroom
```

### Step 4: Create content

Trigger the full pipeline. Returns a run ID for tracking.

```bash
recoup content create --artist <artistAccountId>
recoup content create --artist <artistAccountId> --template artist-caption-bedroom --lipsync
recoup content create --artist <artistAccountId> --songs hiccups,adhd --batch 3
```

| Flag | Required | Description |
|------|----------|-------------|
| `--artist <id>` | Yes | Artist account ID |
| `--template <name>` | No | Template name (default: random) |
| `--lipsync` | No | Enable lipsync mode |
| `--upscale` | No | Enable upscaling |
| `--caption-length <n>` | No | Max caption length in characters |
| `--songs <slugs>` | No | Comma-separated song slugs to limit clip selection |

### Step 5: Monitor the run

```bash
recoup tasks status --run <runId>
recoup tasks status --run <runId> --json
```

### End-to-end example

```bash
recoup content templates
recoup content validate --artist abc-123-uuid
recoup content estimate --artist abc-123-uuid --template artist-caption-bedroom
recoup content create --artist abc-123-uuid --template artist-caption-bedroom --lipsync
recoup tasks status --run run_abc123
```

## Artist management

```bash
# List all artists on your account
recoup artists list

# Filter by organization
recoup artists list --org <orgId>

# Filter by specific account
recoup artists list --account <accountId>

# JSON output for scripting
recoup artists list --json
```

## Organizations

```bash
recoup orgs list
recoup orgs list --account <accountId>
recoup orgs list --json
```

## Chat management

```bash
# List chats
recoup chats list

# Create a new chat
recoup chats create --name "Release Strategy Q2"

# Create a chat with artist context
recoup chats create --name "EP Launch Plan" --artist <artistId>
```

## Sandboxes

Sandboxes are persistent environments where agents run. Create one to execute code, manage files, and run workflows.

```bash
# List active sandboxes
recoup sandboxes list

# Create a new sandbox
recoup sandboxes create

# Run a command in a sandbox
recoup sandboxes create --command "ls -la"
```

## Notifications

Send emails to the authenticated account. The recipient is resolved from your API key.

```bash
# Plain text email
recoup notifications --subject "Weekly Pulse" --text "Here's your summary."

# HTML email
recoup notifications --subject "Weekly Pulse" --html "<h1>Report</h1><p>Active campaigns: 3</p>"

# With CC
recoup notifications --subject "Update" --cc manager@example.com --text "New release scheduled."
```

| Flag | Required | Description |
|------|----------|-------------|
| `--subject <text>` | Yes | Email subject line |
| `--text <body>` | No | Plain text or Markdown body (rendered as HTML) |
| `--html <body>` | No | Raw HTML body (takes precedence over `--text`) |
| `--cc <email>` | No | CC recipient (repeatable) |
| `--room-id <id>` | No | Room ID for a chat link in the email footer |
| `--account <accountId>` | No | Send to a specific account (org keys only) |

| `recoup orgs list` | List organizations |

| `recoup chats create` | Create a new chat |
| `recoup content templates` | List content templates |
| `recoup content validate` | Check artist readiness |
| `recoup content estimate` | Preview cost and duration |
| `recoup content create` | Trigger content creation |
| `recoup tasks status` | Check task run status |
| `recoup sandboxes list` | List sandboxes |
| `recoup sandboxes create` | Create a sandbox |
| `recoup notifications` | Send a notification email |
