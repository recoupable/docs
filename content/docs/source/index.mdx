reading, and website tools, use the separate [public website API](/public-website-api)
and its [OpenAPI specification](https://recoupable.dev/openapi.json).

## Connect your account

For an AI host, start with [MCP OAuth](/mcp-oauth): sign in to your real account,
approve the intended scope and verify access with a read. For REST integrations,
create an API key in your [account settings](https://chat.recoupable.dev/keys), or
follow the [verified email/PIN flow](/agents). Keep credentials in a secret facility.
An empty roster can be valid; do not create a disposable account to recover access.

## Platform base URL

Platform API requests should be made to:

```bash
https://api.recoupable.dev/api
```

## Authentication

For API-key requests, pass your key in the `x-api-key` header. Read [Authentication](/authentication) for supported credentials and follow each endpoint’s authentication requirements. [Agent signup](/api-reference/agents/signup) and [email verification](/api-reference/agents/verify) are unauthenticated onboarding operations.

1. Navigate to the [API Keys Management Page](https://chat.recoupable.dev/keys)
2. Sign in with your account
3. Create a new API key and copy it immediately (it's only shown once)

```bash
curl -X GET "https://api.recoupable.dev/api/artists?accountId=YOUR_ACCOUNT_ID" \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY"
```

<Warning>
Keep your API key secure. Do not share it publicly or commit it to version control.
</Warning>

## Read with an agent

- [Documentation index](/llms.txt): all guides and endpoints, grouped by topic, with links to Markdown.
- [Full documentation](/llms-full.txt): the complete documentation and operation schemas in one text file.
- [API overview](/api-reference): browse endpoints by topic. Each reference includes its method, path, authentication, request, responses, and specification.
- **Page Markdown:** use **Copy page** or **View as Markdown** on any page. You can also append `.md` to a page URL, or request it with `Accept: text/markdown`.

Use the exact method and path in the endpoint reference; navigation labels are summaries.
Check availability notes before calling an operation. A pending or unavailable feature is
not a callable endpoint. Keep anonymous website tools separate from authenticated account operations.
