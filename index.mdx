---
title: "What is Recoup?"
description: "Infrastructure for agents to operate the music business."
---

Recoup is the agent harness for the music business. APIs, an MCP server, and a CLI for the agents and developers running labels, distributors, catalog companies, management firms, and independent artists. Agents do the work that used to take a full team, programmatically.

## Three interfaces

<CardGroup cols={3}>
  <Card
    title="REST API"
    icon="code"
    href="/quickstart"

    Standard HTTP endpoints. Pass your API key in `x-api-key` and call any of them.
  </Card>
  <Card
    title="MCP Server"
    icon="cpu"
    href="/mcp"
  >
    Connect Claude, ChatGPT, Cursor, or any MCP-compatible agent directly. One URL.
  </Card>
  <Card
    title="CLI"
    icon="terminal"
    href="/cli"
  >
    `recoup whoami` to verify, `recoup artists list` to explore. Install with `npm i -g @recoupable/cli`.
  </Card>
</CardGroup>

## Base URL

```
https://api.recoupable.com/api
```

All endpoints require `x-api-key` header authentication unless noted. See [Authentication](/authentication) for the full auth model and [Credits](/credits) for what's billed.
